Common Issues & Solutions

Issue 1: Button clicks but nothing happens
Solution: Hard refresh the browser
• Windows: Ctrl + Shift + R
• Mac: Cmd + Shift + R
Issue 2: Console shows errors
Solution: Check specific error message:
• "openCertModal is not defined" → File not saved properly, refresh again
• "Cannot read property 'title'" → Certificate data missing
• "getElementById(...) is null" → Modal HTML missing
Issue 3: Still freezing/not working
Solution: Clear all browser cache:
1. Press Ctrl + Shift + Delete
2. Select "Cached images and files"
3. Click "Clear data"
4. Refresh certifications.html
