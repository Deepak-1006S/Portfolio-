
# Personal Portfolio Website

A clean, responsive, and lightweight personal portfolio website built to showcase my projects, skills, and journey as a developer. 

## 🌐 Live Demo
You can view the live website here: [deepak-portfolio-06.vercel.app](https://deepak-portfolio-06.vercel.app/)

---

## 🚀 Features
* **Fully Responsive:** Optimised for desktop, tablet, and mobile viewing.
* **Modular Structure:** Separate pages for clean navigation (`index`, `about`, `skills`, `projects`, `contact`).
* **Dynamic Navigation:** Smooth mobile navigation handling via JavaScript.
* **Fast Deployment:** Configurations ready for seamless deployment on Vercel.

---

## 🛠️ Tech Stack
* **HTML5:** Semantic structure for better SEO and accessibility.
* **CSS3:** Custom styling and responsive layouts.
* **JavaScript (ES6):** Interactive UI components and responsive menu logic.
* **Deployment:** Hosted on Vercel.
